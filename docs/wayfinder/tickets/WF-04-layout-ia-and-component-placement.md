## Question

在「保留左栏自动目录，其余模块自由重新设计摆放」的约束下，用 ASCII 线框图与空间网格规范确定各核心页面的信息架构：

1. **页面网格与对齐**：文章页、首页/文章列表页、归档页、分类/标签页在桌面宽屏、中等屏幕与移动端的分栏策略与对齐方式（是否保持三栏、还是文章页采用双栏+按需抽屉、或非对称编辑部网格）。
2. **核心组件重新摆放**：顶栏导航、站点公告/作者简介、分类筛选条、文章列表项形态、文章元信息（阅读时长/字数/分类与标签）、文末版权块、续读提示、暗色/主题切换入口分别摆放在哪里、呈现何种视觉层级？
3. **跨页连贯性**：如何在不破坏博客园 View Transition 与首帧防白闪机制的前提下，保持首页到文章页的空间切换自然流畅？

## Resolution

1. **核心网格形态：非对称两栏阅读工作台（去常驻右栏）**
   - **桌面端（`>= 960px`）**：左侧固定宽度 `240–260px`（`Mantle` 表面、sticky 定位）作为标尺导轨栏，右侧为宽裕的 `Base` 主阅读画布（文章页正文左对齐、`max-width: 66–74ch`、右侧自然留白；列表页最大宽度约 `76ch`、左对齐）。
   - 彻底隐藏博客园原生的嘈杂右侧边栏小部件（`#sideBar` 仅提取公告、归档月份等所需数据，不再以右栏卡片形式展示），全站首页与文章页共享同构两栏骨架以保证切页不跳动。
2. **顶栏与跨页连贯性**
   - 顶栏位于 `Crust` 表面，高度 `52px`，底边 `1px` `Surface 0` 细线，隐藏博客园原生 `#top_nav` 与 `#header`。
   - 结构：左侧站点名 + 紧邻主导航（首页 / 归档 / 分类 / 标签）+ 右侧极简工具区（暗色模式切换，及视 `WF-05` 决定是否提供强调色入口）。
   - 保留解析期 `document.write` 预渲染静态顶栏与 render-blocking `@view-transition`（`view-transition-name` 锁定顶栏原地无闪烁过渡）。
3. **各核心页面左栏与主画布分工**
   - **文章页**：左栏专注「标尺导轨式自动目录（Reading Rail）」，目录底部收敛桌面端「回到顶部 + 阅读进度」控件（文字 + 细进度条，取消桌面右下角悬浮球）；主画布依次为无卡片题头（H1 + 自然留白分组的日期/阅读时长/字数/分类/`Surface 0` 标签胶囊，禁 `·` 中点串联与 ALL-CAPS 眉标）→ 正文 → `1px` 分隔线 + 低存在感 `Mantle` 版权说明块 → 上下篇与评论区。
   - **首页 / 列表页**：左栏承接原博客公告/站点简介 + 本页文章或快捷分类索引；主画布顶部放置分类筛选条，下方为无阴影、无 hover 浮起的平铺文章条目列表（标题 + 两行克制摘要 + 元信息 + `1px` 细线分隔）。
   - **归档页**：左栏复用标尺导轨作为年月快速跳转索引，主画布为全站异步懒加载时间线。
   - **分类页 / 标签页**：左栏提供分类/热门标签速览，主画布将博客园原生 `<table>` 重塑为平铺网格。
   - **续读记忆**：底部轻量 Toast（含「回到开头」动作按钮），5 秒自动消失或手动关闭。
4. **响应式断点（`< 960px`）**
   - 切为单栏全宽 `Base` 画布（强制 `align-items: stretch` 与 `max-width: 100%` 防宽代码块撑破横向滚动条）；
   - 顶栏导航折叠为右侧滑出抽屉；文章页左下角提供「目录」按钮拉起底部抽屉（Bottom Sheet），并显示简洁回到顶部入口。
