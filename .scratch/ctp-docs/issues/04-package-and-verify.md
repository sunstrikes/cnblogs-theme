# 04: 生成可安装的主题包并验收发布版本

**What to build:** 博主用 Python 3 标准库生成可粘贴到博客园后台的托管包和完整内联样式备份。发布前能在本地验证实际产物及其故障回退，不需要上线博客，也不能用源码预览代替产物验收。

**Blocked by:** 02（读完一篇长技术文章，下次接着读）、03（从首页、分类、标签和归档找到文章）

**Status:** ready-for-agent

- [ ] 从干净的输出目录运行构建，无需安装第三方构建依赖，即可得到完整及压缩 CSS、含备用 CSS 的 JS、后台定制 CSS 与页首 HTML 粘贴包，以及单文件内联 CSS 备份。产物一致时 `--check` 成功；手动改动生成内容或造成版本不一致时，检查失败。
- [ ] 把生成内容放入离线页面对应的后台字段：托管 CSS 标记为 `--ctp-field:2`，内联备份标记为 `--ctp-field:1`。模拟博客园对外链脚本添加 `defer`，解析期顶栏和首帧主题仍生效；切换到内联样式备份后不依赖外部 CSS。
- [ ] 用本地可控的网络响应验证两条回退路径：主 CDN 失败则切换备源，1 小时熔断期内再次访问跳过主源，到期可重试；两个 CSS 源均失败但 JS 可用时，页面由包内 CSS 恢复主题。检查托管资源的缓存键随小时更新。
- [ ] 用实际粘贴包离线运行首页、文章、归档、标签四类真实 DOM 快照。运行各功能票的回归，确认侧栏隐藏但数据可读、目录只有一个当前项、同日多篇不丢失、两种代码高亮均可复制和折叠。
- [ ] 每类页面留存 1440×900、1920×1080、390×844 三档视口各自的 Latte 和 Mocha 截图，共 24 张。窄屏断言整页无横向溢出；用键盘检查可见焦点及抽屉 Esc 关闭，启用减少动态效果后仍可导航。
