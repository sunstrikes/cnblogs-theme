# 03: 从首页、分类、标签和归档找到文章

**What to build:** 读者可在首页逐篇浏览，也可按分类、标签或年月找到文章。本票负责首页和文章题头的分类、标签入口，共用同一套分类数据；可直接用 01 的文章快照验收，不等待 02 的排版和阅读时长。

**Blocked by:** 01（打开文章并按章节导航）

**Status:** resolved

- [x] 在真实首页快照中，同一天发布的多篇文章各有独立条目，保留标题链接、摘要和元信息。左栏快速索引逐篇对应，翻页后仍指向本页文章；列表居中且不超过 880px。
- [x] 延迟填充原生侧栏时，页面仍能显示；数据到达后，首页左栏能读到原生公告。配置 `notice.html` 时改用指定内容，不重复展示公告，也不恢复可见右栏。
- [x] 首页分类条遵守 `categories.show`、`include` 和 `max`。在题头没有原生分类或标签节点的文章上，也能结合文章关键词与分类数据区分两者；首页和题头的入口均能打开对应列表。
- [x] 用与真实页面一致的分类块和标签表分别验收平铺网格，不假定两者结构相同。点击某一分类或标签后，结果列表中的文章链接仍可打开。
- [x] 默认归档导航中的年月解析为有效月份。用真实归档快照及本地月份响应验收：左栏按原生侧栏列出年月，点击月份或滚动能懒加载对应文章；模拟某月失败或延迟，当前内容仍可读，其他月份仍可访问。
- [x] 将真实首页、归档、标签页快照及所需响应纳入离线回归；断开外网仍可验证同日多篇、分类与标签入口、归档选月。只读参考主题不承载测试改动。

**依据：** [设计规格 §3.2、§4、§5](../../../docs/DESIGN-SPEC.md)；[各类列表及异步侧栏的实际 DOM](../../../docs/research/cnblogs-theme-audit.md)。

**验收记录（2026-11-25）：** [列表与归档回归](../../../preview/test_discovery.py)覆盖同日多篇、异步插入、纯图片公告、分类与标签同名以及月份请求失败。另用原生响应回放：首页及历史分页各保留 10 条原始文章链接和 10 条索引。移除侧栏月份响应后，从首页、文章、标签目录及月份页都能进入有文章的 `2025/06` 归档。
