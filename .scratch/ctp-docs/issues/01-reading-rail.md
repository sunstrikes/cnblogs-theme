# 01: 打开文章并按章节导航

**What to build:** 读者打开博客园 Custom 皮肤的文章，首帧就看到选定的主题；桌面用左侧 Reading Rail 定位章节，手机用底部目录选章。即使脚本或侧栏数据未到，文章也能阅读。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 用一条本地命令打开真实文章 DOM 快照，断开外网仍可运行本票的检查。以快照而非静态视觉原型验收；参考主题保持只读。
- [x] 960px 及以上显示居中的工作台：52px 顶栏、264px 左栏、最大 840px 的文章区。Reading Rail 仅收录正文 H1 至 H4；点击能定位到对应标题，滚动时只有一个当前项，以 3px 游标和强调色文字标示，不加底色。
- [x] 低于 960px 切为单栏；站点导航从右侧打开，文章目录从底部打开。键盘可操作并能用 Esc 关闭；选章后能看到目标标题。开启减少动态效果时无需等待过渡动画。
- [x] 在保存的选择、站点默认和系统偏好互相冲突的用例中，首帧依此次序选用 Latte 或 Mocha。顶栏可切换并记住选择；默认强调色为 Mauve，四种可配置强调色均可用，顶栏不出现取色器。站点名留空时取博客名，设置站点名、导航或图标后使用配置值。
- [x] 跨文档导航时，页首解析阶段已有静态顶栏，运行时接管后仍只有一个；在支持 View Transition 的浏览器中切页，顶栏不消失、不闪白。
- [x] 原生右栏不占可见布局，异步容器仍在原位并可接收数据。延迟注入正文、侧栏容器或侧栏内容，目录仍能读取已到达的标题；数据迟迟未齐时，JS 在 1.5 秒放行。单独禁用 JS，CSS 在 2.5 秒后让正文可见。

**依据：** [设计规格 §1、§2、§3.2、§4.1、§4.3、§5](../../../docs/DESIGN-SPEC.md)；[博客园 DOM 审计](../../../docs/research/cnblogs-theme-audit.md)。

**验收记录（2026-11-25）：** [阅读导轨回归](../../../preview/test_rail.py)覆盖桌面选章、键盘抽屉、无标题短文、跨页顶栏和超时放行；[发布包回归](../../../preview/test_package.py)另测托管 CSS 晚到的首帧。回放原生文章时，1440px 下左栏实测为 264px，390px 下整页宽度为 390px。
