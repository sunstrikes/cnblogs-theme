# 02: 读完一篇长技术文章，下次接着读

**What to build:** 读者可以在文章页估计阅读时间，阅读或复制代码，继续浏览评论，下次打开同一篇时回到之前的位置。用真实文章快照验收；题头的分类和标签入口由 03 负责，不作为本票前置条件。

**Blocked by:** 01（打开文章并按章节导航）

**Status:** resolved

- [x] 文章题头展示日期、字数和阅读时长。正文使用规格中的字体栈与标题间距，H2 无底线；Latte 和 Mocha 下链接有下划线，引用与五类语义提示块可区分，MathJax 和 KaTeX 公式继承正文前景色。
- [x] 在手机视口打开含宽表、长代码行和图片的文章，宽内容在自身区域内展示或滚动，整页没有横向溢出；正文图片按需加载。
- [x] 对 Highlight.js 和 Prism 各验收一例：两套主题下均按语法角色着色，工具条显示语言，复制结果等于完整原文而非可见片段。默认 34 行不折叠、35 行折叠且可展开；改动 `code.collapseLines` 后按新阈值执行。富文本 `.cnblogs_code` 不新增工具条或重复行号。
- [x] 文末显示平铺版权块，可更改许可或关闭显示。上下篇链接仍可访问；异步出现的评论和表单在两套主题下均可读、可操作。打印预览为白底深字，不含顶栏、左栏或抽屉。
- [x] 桌面左栏底部的百分比与细进度条随滚动更新，桌面和手机的回顶入口均能回到开头。重开同一长文会恢复位置；续读提示可手动关闭、可回到开头，不操作时 5 秒后消失。关闭 `resume.show` 后不恢复位置、不弹提示。

**依据：** [设计规格 §2.3、§3、§4.3、§5](../../../docs/DESIGN-SPEC.md)；[配色与可读性基线](../../../docs/research/catppuccin-palette-guidelines.md)。

**验收记录（2026-11-25）：** [文章阅读回归](../../../preview/test_reading.py)覆盖复制、折叠、续读、打印和评论，并记录屏外图片的网络请求。原始 HTML 带 `loading="lazy"` 或仅含 `data-src` 时，测试中的两张图片均在接近视口后才请求。旧文章若只含普通 `src`，浏览器可能在主题运行前发出请求；[图片写法](../../../README.md#正文图片的延迟加载)说明了这个边界。
