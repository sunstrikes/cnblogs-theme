用三阶平面分层重塑博客园长文阅读体验

2026-11-25 约 8 分钟 3,420 字 前端架构 Catppuccin CSS Grid 设计系统

为什么放弃浮空白卡

大多数博客主题习惯在浅灰底色上堆叠圆角白卡与柔和阴影，再把公告、排行、标签云全部塞进右侧边栏。对于短消息流这很合理，但面对需要连续专注二十分钟的技术长文，视觉边框与四周噪音会不断打断阅读节奏。

Catppuccin 三阶平面分层

Catppuccin 官方色板天然提供了 Base、Mantle、Crust 三层克制的背景阶梯，相邻明度差仅在 1.07–1.17:1 之间。利用这种微弱色阶，我们可以完全取消卡片阴影，把正文铺在 Base 连续画布上，左栏目录与代码块落在 Mantle，顶栏壳层落在 Crust。

把大胆的视觉辨识度只花在一处——左栏标尺导轨（Reading Rail），其余界面保持安静与克制。

Latte 浅色对比度红线

实测表明，Mocha 暗底上 14 种强调色全部达到 WCAG AAA，但 Latte 浅底上只有 Mauve 与 Red 满足正文 AA 对比度。因此默认品牌色锁定 Mauve，正文超链接则交由 Blue 配合克制下划线承担。

代码块双引擎语法映射

typescript 
1// 根据系统偏好与本地缓存同步 Catppuccin 风味
2export function resolveFlavor(stored: string | null): 'latte' | 'mocha' {
3  if (stored === 'latte' || stored === 'mocha') return stored;
4  const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
5  return prefersDark ? 'mocha' : 'latte';
6}
提示：Latte 浅色模式下代码注释采用 Overlay 2（#7c7f93），避免 Overlay 0 在浅灰代码底上发虚。

博客园真实 DOM 契约

由于博客园异步加载侧栏并把正文排在 DOM 前方，主题在生产代码中继续依赖 #sideBar { display: contents } 与 --qb-field 首帧闸门，确保首绘即终态且不破坏跨文档 View Transition。
